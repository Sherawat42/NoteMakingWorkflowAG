## Section: Equilibrium Output — Graphical Analysis (2.3.1 cont.)
<!-- See Chunk 011 for the algebraic derivation -->

### Core Idea

The graphical analysis of Keynesian equilibrium uses the **45-degree diagram** (also called the Keynesian cross). Along the horizontal axis is output/income (Y); along the vertical axis is aggregate demand and its components. The 45° line (OL) represents points where Y = AD. Equilibrium occurs at the unique intersection of the AD curve with the 45° line — where planned expenditure exactly equals output and there are **no unplanned inventory changes**.

### Key Concepts

#### Two-Sector Economy Equilibrium

In a two-sector economy (households and firms only), AD = C + Ī. Setting G = T = 0:

**Yₑ = (a + Ī) / (1 − b)** ... (2.5)

The AD line is parallel to the consumption function (since adding autonomous Ī shifts the intercept but doesn't change the slope 'b'). Equilibrium at point E in Fig. 2.3, where EYₑ (demand) = OYₑ (output).

#### Three-Sector Economy Equilibrium

Adding government, AD = C + Ī + G. The AD line shifts further up. Equilibrium in Fig. 2.4 occurs at the intersection with the 45° line. The key insight remains: **higher autonomous spending (I, G, a) → higher AD curve → higher equilibrium output**.

#### The 45° Line Construct

The OL line at 45° creates isosceles triangles, allowing vertical distances (demand) to be compared with horizontal distances (output). At point A where the consumption function crosses OL, consumption exactly equals income (saving = 0). This is the **break-even point**.

#### Demand-Determined Output

Since the position of the AD curve depends on autonomous spending components, changes in I, G, or autonomous consumption directly shift AD and change equilibrium output. This is the fundamental Keynesian mechanism: **aggregate demand drives output**, not the other way around.

## Section: Investment Multiplier (2.3.2)

### Core Idea

The **multiplier** is one of the most important concepts in Keynesian economics. It shows that a one-time increase in autonomous investment (ΔI) causes a **multiple increase in equilibrium income** (ΔY > ΔI). The multiplier equals 1/(1−b), where b is the MPC. The mechanism works through successive rounds of spending: the initial injection becomes someone's income, who spends a fraction 'b' of it, generating further income and spending, in a converging geometric series.

### Key Concepts

#### Multiplier Formula

From the equilibrium output equation, if autonomous investment changes by ΔI (with other autonomous components unchanged):

**ΔY = [1/(1 − b)] × ΔI**

Therefore: **ΔY/ΔI = 1/(1 − b)** — the investment multiplier

Since 0 < b < 1, the multiplier 1/(1−b) > 1. For example:
- If b = 0.5 → multiplier = 2 (income rises by 2× the initial investment increase)
- If b = 0.75 → multiplier = 4
- If b = 0.9 → multiplier = 10

#### Round-by-Round Multiplier Process

The multiplier works through successive spending rounds:
1. **Round 1**: Autonomous investment increases by ΔI → income rises by ΔI
2. **Round 2**: Additional income ΔI induces consumption of bΔI → income rises by bΔI
3. **Round 3**: Additional income bΔI induces consumption of b²ΔI → income rises by b²ΔI
4. **Round 4**: Consumption = b³ΔI → income rises by b³ΔI
5. **Process continues** with each round generating a smaller increment (since b < 1)

**Total income increase**: ΔY = ΔI(1 + b + b² + b³ + ...) ... (2.6)

Since 0 < b < 1, this is a convergent infinite geometric series with sum = 1/(1−b):

**ΔY = [1/(1−b)] × ΔI**

#### Why the Multiplier Works

The multiplier is possible because **output is demand-determined** — there are unemployed resources that can be mobilized when demand increases. Each round of spending generates new income, part of which is consumed (fraction b), creating further demand and production. The process converges because the marginal propensity to save (1−b) represents leakage from the spending stream.

#### Role of MPC in Multiplier Size

The multiplier is larger when the MPC (b) is higher:
- Higher MPC → less leakage through saving → more of each round's income is respent → larger cumulative effect
- Lower MPC → more leakage → weaker respending → smaller multiplier

### Definitions

- **Investment Multiplier**: The ratio ΔY/ΔI = 1/(1−b), showing the multiple by which equilibrium income changes for a given change in autonomous investment. Always greater than 1 when 0 < b < 1.
- **Convergent Geometric Series**: The mathematical basis for the multiplier — the infinite sum 1 + b + b² + b³ + ... = 1/(1−b) when |b| < 1.

### Open Questions

1. Does the multiplier work in reverse (a decrease in I causing a multiple decrease in Y)? Yes — the same process operates symmetrically for reductions in autonomous spending.
2. What limits the multiplier in practice? Capacity constraints, import leakage, and crowding out effects can reduce the actual multiplier below 1/(1−b).
