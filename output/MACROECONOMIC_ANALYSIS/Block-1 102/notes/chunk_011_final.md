## Section: Investment Function — Continued (2.2.2)
<!-- See Chunk 010 for the beginning of this section -->

### Core Idea

The interest rate affects investment through the **present value mechanism**. An investment project costs Rs. A and yields returns R₁, R₂, ..., Rₜ over T periods. The present value (P) of this return stream is calculated by discounting each future return at the interest rate 'i'. A project is undertaken only if its present value exceeds or equals its cost (P ≥ A). Higher interest rates reduce P, making fewer projects profitable and reducing aggregate investment. The full investment function incorporating interest rate is: **I = c + dY − ei**, where e captures interest responsiveness.

### Key Concepts

#### Present Value and Investment Decision

For a project costing A with returns R₁, R₂, ..., Rₜ over T periods at interest rate i:

**P = R₁/(1+i) + R₂/(1+i)² + R₃/(1+i)³ + ... + Rₜ/(1+i)ᵀ** ... (2.2c)

The project is undertaken only if **(P − A) ≥ 0**. This is the profit-maximizing investment criterion.

#### Interest Rate–Investment Inverse Relationship

At interest rate i₀, the economy's investment I₀ consists of all projects where P ≥ A. When i rises to i₁ (with returns Rₜ and cost A unchanged), P falls for every project. Some previously profitable projects (where P ≥ A) now become unprofitable (P < A). Therefore, investment falls: **when i₀ > i₁, we have I₀ < I₁** (lower interest → higher investment).

#### Full Investment Function with Interest Rate

Including the interest rate:

**I = c + dY − ei** ... (2.2d)

where c > 0 (autonomous component), d > 0 (MPI), e > 0 (interest sensitivity). The parameter 'e' captures how responsive planned investment is to changes in the interest rate. This specification becomes critical in the IS-LM model (Unit 3).

### Examples

**Present Value Calculation**: If you lend ₹100 at 10% for 1 year, you receive ₹110. The present discounted value of ₹110 at 10% is ₹100 [since 100 = 110/(1+0.1)]. This illustrates how future returns are worth less today when discounted at the interest rate.

## Section: Determination of Output in the Keynesian Model (2.3)

### Core Idea

The Keynesian model of output determination rests on three critical assumptions: (1) there are **unemployed resources** and underutilized capacity in the economy; (2) **wages and prices are rigid** — since workers are willing to work at the going wage rate, output can increase at the given price level; (3) output is a **homogeneous commodity** used for both consumption and investment. Under these conditions, **output is demand-determined** — existing production capacity can be used to increase production when aggregate demand rises.

### Key Concepts

#### Model Setup — Three-Sector Economy

The model considers a closed economy with three sectors: households, firms, and government. Aggregate demand = C + I + G:

**AD = a + b(Y − T) + Ī + G** ... (2.3)

where T is a lump-sum tax, I is autonomous, and G is government expenditure.

#### Equilibrium Condition

Equilibrium occurs when Aggregate Supply = Aggregate Demand:

**Y = a + b(Y − T) + Ī + G**

Solving for equilibrium output (Yₑ):

Y − bY = a − bT + Ī + G

**Yₑ = (a − bT + Ī + G) / (1 − b)** ... (2.4)

Equilibrium output is higher at higher levels of autonomous investment, government expenditure, and the MPC. Since 0 < b < 1, the denominator (1 − b) is always positive.

#### Demand-Determined Output

The position of the AD curve is determined by autonomous spending components (I, G, autonomous consumption 'a'). Higher autonomous spending → higher AD line → higher equilibrium output. This demonstrates the fundamental Keynesian proposition: **output is demand-determined**.

### Mechanisms / Processes

#### Stability of Equilibrium

1. **Below equilibrium** (Y < Yₑ): Aggregate demand > output → firms' inventories run down (unplanned inventory decumulation) → firms increase production → output rises toward Yₑ
2. **At equilibrium** (Y = Yₑ): Demand = output → no unplanned inventory changes → production stays constant
3. **Above equilibrium** (Y > Yₑ): Output > aggregate demand → unplanned inventory accumulation by firms → firms reduce production → output falls toward Yₑ

The equilibrium is **unique and stable**: any disequilibrium is self-correcting.

**Figure 2.3: Two-Sector Equilibrium** — 45° diagram. AD = C + Ī is parallel to the consumption function (same slope 'b'). Equilibrium at E where AD intersects the 45° line (OL).
