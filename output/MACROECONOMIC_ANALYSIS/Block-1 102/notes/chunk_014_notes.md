## Section: Limitations of the Keynesian Model (2.3.5)

### Core Idea

The Keynesian model's multiplier mechanism has important limitations. It is most relevant for an economy facing **recessionary conditions** with excess production capacity. In economies with supply constraints, demand increases cause **price rises rather than output increases**. Similarly, in economies operating near full employment, output expansion requires factor and goods price increases. The model is best suited for **short-run analysis** — wage contracts and posted prices remain fixed for some time, making the sticky-price assumption reasonable.

### Edge Cases & Caveats

Three key limitations:
1. **Supply-constrained economies**: If there are supply bottlenecks (insufficient raw materials, infrastructure, skilled labor), increased demand cannot translate into higher output — only into higher prices
2. **Near full-employment economies**: When the economy is already at or near full capacity, further demand stimulus is mostly inflationary
3. **Short-run applicability only**: The assumption of wage and price rigidity is reasonable only for the short run. Wage contracts last for defined periods; price catalogs are valid for some time. In the long run, prices and wages do adjust, and the classical model becomes more relevant.

## Section: Alternative View of Equilibrium (2.4)

### Core Idea

The Keynesian model can be recast using the **saving-investment** relationship. Instead of the AD = Y formulation, equilibrium occurs when planned saving equals planned investment (S = I). This "leakage-injection" approach is mathematically equivalent to the AD = Y approach but provides additional insight — particularly useful for understanding the **paradox of thrift**.

## Section: Saving Function (2.4.1)

### Core Idea

The saving function is the **mirror image** of the consumption function. Since income is either consumed or saved (Y = C + S), the saving function can be derived directly from the consumption function. The decision to consume more is identical to the decision to save less.

### Key Concepts

#### Derivation of the Saving Function

From Y = C + S and C = a + bY:

**S = Y − (a + bY) = −a + (1−b)Y** ... (2.12)

Key features:
- **Intercept = −a** (negative): At zero income, saving is negative (dis-saving equal to autonomous consumption)
- **Slope = (1−b)** = MPS (Marginal Propensity to Save)
- **MPS + MPC = 1**, so higher MPC means lower MPS

#### Break-Even Income

At income Y₂ where the consumption function crosses the 45° line, C = Y and S = 0. This is the break-even point:
- Below Y₂: planned consumption exceeds income → **negative saving** (dis-saving)
- At Y₂: planned consumption equals income → **zero saving**
- Above Y₂: income exceeds planned consumption → **positive saving**

### Definitions

- **Saving Function**: S = −a + (1−b)Y — the relationship between planned saving and income, derived from the consumption function.
- **Marginal Propensity to Save (MPS)**: (1−b) = ΔS/ΔY — the fraction of additional income that is saved. Always equal to (1 − MPC).
- **Dis-saving**: Negative saving — occurs when consumption exceeds income, financed by drawing down past savings. Happens at income levels below the break-even point.

## Section: Determination of Equilibrium Output via S = I (2.4.2)

### Core Idea

In a two-sector economy, equilibrium output occurs where **planned saving equals planned investment**. Since Y = C + I at equilibrium and Y = C + S by identity, it follows that S = I. This is an equivalent way to determine equilibrium — the leakage from the spending stream (saving) must exactly equal the injection into the stream (investment).

### Key Concepts

#### S = I Equilibrium Derivation

From the equilibrium condition (Y = C + I) and the income identity (Y = C + S):
- C + S = C + Ī
- Therefore: **S = Ī** ... (2.13)

Planned saving must equal planned investment. If S > I, income falls (planned expenditure < output). If S < I, income rises (planned expenditure > output). Equilibrium is reached only when the saving leakage is exactly offset by the investment injection.

### Connections

- This S = I formulation is **mathematically equivalent** to the AD = Y approach in Section 2.3.1 (Chunk 011)
- The S = I framework becomes the basis for the **paradox of thrift** in Section 2.4.3 (Chunk 015)
- In the classical model, S = I is achieved through **interest rate adjustment** (loanable funds market); in the Keynesian model, it is achieved through **income adjustment** (multiplier process)
