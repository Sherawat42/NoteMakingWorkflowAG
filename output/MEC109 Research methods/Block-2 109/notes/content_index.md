## Key Terms Glossary

| Term | Definition | First Appears |
|------|-----------|--------------|
| Research Design | Logical structure of an enquiry specifying the type of evidence needed | Chunk 001 |
| Research Methods | Tools and techniques of data collection and data analysis | Chunk 001 |
| Mixed Methods Research | Combining ≥1 QN and ≥1 QL component in a single study | Chunk 001 |
| Parameter | Any function of population values (e.g., population mean M) | Chunk 003 |
| Statistic | Any function of sample observations (e.g., sample mean m) | Chunk 003 |
| Estimator | Sample statistic used to estimate a population parameter | Chunk 003 |
| Representative Sample | Sample with population characteristics in same proportion as in population | Chunk 003 |
| Random Sampling | Each unit has a predetermined, known probability of inclusion | Chunk 003 |
| Standard Error | Standard deviation of sampling distribution of an estimator | Chunk 004 |
| Confidence Interval | Range within which population parameter lies with stated probability | Chunk 004 |
| SRSWR | Random sampling with replacement; units can repeat | Chunk 004 |
| SRSWOR | Random sampling without replacement; n distinct units; uses FPC | Chunk 004 |
| Finite Population Correction | Factor (N–n)/(N–1) reducing variance in SRSWOR | Chunk 004 |
| I-PSS | Sub-samples providing unbiased V(t) estimate for any design | Chunk 004 |
| Systematic Sampling | Every k-th unit from random start r; k = [N/n] | Chunk 004 |
| PPS Sampling | Selection probability proportional to unit size (auxiliary variable) | Chunk 004 |
| Stratified Sampling | Population divided into strata; independent samples from each | Chunk 005 |
| Cluster Sampling | Clusters selected; all units within selected clusters surveyed | Chunk 005 |
| Measurement | Assigning numbers to characteristics of objects according to rules | Chunk 006 |
| Nominal Scale | Classification/naming only; no order; mode/chi-square applicable | Chunk 006 |
| Ordinal Scale | Rank order; unequal intervals; median/percentile applicable | Chunk 006 |
| Interval Scale | Equal intervals; no absolute zero; mean/SD/t-test applicable | Chunk 006 |
| Ratio Scale | Equal intervals + absolute zero; all statistics applicable | Chunk 006 |
| Reliability | Degree of consistency of a measurement | Chunk 006 |
| Validity | Degree to which instrument measures what it claims to measure | Chunk 006 |
| Comparative Scaling | Direct comparison of objects; ordinal data | Chunk 006 |
| Likert Scale | 5-point summated rating scale; interval data | Chunk 007 |
| Semantic Differential Scale | 7-point bipolar scale; factor-analysable; interval | Chunk 007 |
| Stapel Scale | –5 to +5 single-criterion; interval; no neutral zero | Chunk 007 |
| Guttman Scale | Cumulative scale; unidimensional; ordinal | Chunk 007 |
