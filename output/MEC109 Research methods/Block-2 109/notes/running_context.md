# Running Context
**Source**: Block-2 109 (MEC109 Research Methods)

## Key Concepts Introduced
- **Types of Research** (Chunk 001): Theoretical/Applied, Descriptive/Explanatory, Quantitative/Qualitative, Conceptual/Empirical, Exploratory, Experimental, Evaluative, Action Research
- **Research Design** (Chunk 001): Logical structure of enquiry; specifies evidence needed to answer research questions
- **Research Design vs. Research Methods** (Chunk 001): Design = logical structure; Methods = tools of data collection and analysis
- **Mono Methods** (Chunk 001): Research using only QN or only QL methods
- **Mixed Methods Research** (Chunk 001): Combining ≥1 QN and ≥1 QL component in a single study
- **Methods of Data Collection** (Chunk 003): Census/Survey, Observation, Experimental
- **Tools of Data Collection** (Chunk 003): Questionnaire (respondent fills), Schedule (investigator elicits); primary vs. secondary data; sampling and non-sampling errors
- **Parameter vs. Statistic** (Chunk 003): Population value = parameter (UPPER CASE); sample value = statistic (lower case)
- **Inference** (Chunk 003): Process of drawing conclusions about population from sample results
- **Non-Random Sampling** (Chunk 003): Judgment, Convenience, Purposive, Quota, Heterogeneity, Snowball — no known probability; not representative
- **Random/Probability Sampling** (Chunk 003): Each unit has a predetermined probability; enables valid inference and precision quantification

## Definitions (⭐ exam-important)
- **Quantitative Variable** (Chunk 001): Variable whose values can be expressed numerically (e.g., yield, height)
- **Qualitative Variable** (Chunk 001): Variable expressed as categories or choices (e.g., gender, opinion)
- **Research Design** (Chunk 001): Logical structure of enquiry; ensures unambiguous answers to research questions ⭐
- **Research Methods** (Chunk 001): Tools and techniques of data collection and data analysis ⭐
- **Mixed Methods Research** (Chunk 001): Combining ≥1 QN and ≥1 QL component in a single study ⭐
- **Empirical Research** (Chunk 001): Data-based research verifiable by observation and experiment
- **Census** (Chunk 003): Complete enumeration — data from all population units ⭐
- **Primary Data** (Chunk 003): Data collected fresh by the conducting agency for the specific enquiry ⭐
- **Secondary Data** (Chunk 003): Data previously collected by another agency ⭐
- **Parameter** (Chunk 003): Any function of population values (e.g., population mean M) ⭐
- **Statistic** (Chunk 003): Any function of sample observations (e.g., sample mean m) ⭐
- **Estimator** (Chunk 003): Sample statistic used to estimate a population parameter ⭐
- **Estimate** (Chunk 003): Value of the estimator from a specific sample ⭐
- **Inference** (Chunk 003): Drawing conclusions about a population from sample results ⭐
- **Sampling Error** (Chunk 003): Error from using a sample estimate instead of the true parameter
- **Representative Sample** (Chunk 003): Sample with population characteristics in same proportion as population ⭐
- **Random Sampling** (Chunk 003): Each unit has a predetermined, known probability of inclusion ⭐
- **Sampling Design** (Chunk 003): Specification of all possible samples with their probabilities ⭐
