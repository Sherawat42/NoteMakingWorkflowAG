## Key Terms Defined
- **Research**: A systematic and organised search for relevant information on a specific topic
- **Pure/Fundamental Research**: Aims at increasing knowledge base without practical application
- **Applied Research**: Aims to find solutions to practical problems using existing knowledge
- **Exploratory Research**: Conducted when little is known about the topic; aims to generate hypotheses
- **Descriptive Research**: Describes characteristics of a phenomenon or population; uses surveys
- **Causal/Explanatory Research**: Establishes cause-effect relationships; uses experiments
