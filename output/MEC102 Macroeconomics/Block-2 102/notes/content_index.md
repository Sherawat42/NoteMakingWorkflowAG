## Key Terms Glossary
| Term | Definition | First Appears |
|------|-----------|---------------|
| Inflation | Persistent rise in the general level of prices. | Chunk 001 |
| Demand-pull inflation | Inflation caused by an increase in aggregate demand. | Chunk 001 |
| Cost-push inflation | Inflation caused by an increase in costs of production. | Chunk 001 |
| Built-in inflation | Inflation caused by past events (expectations baked into contracts). | Chunk 001 |
| Labour Force | Persons aged 16–64 willing to work; employed + unemployed. | Chunk 001 |
| Work Force | The employed persons only (subset of labour force). | Chunk 001 |
| Involuntary Unemployment | Willing to work at the prevailing wage but cannot find work. | Chunk 001 |
| Frictional Unemployment | Unemployment due to job-switching, search/matching, migration. | Chunk 001 |
| Structural Unemployment | Unemployment due to skill-mismatch / structural shifts. | Chunk 001 |
| Cyclical Unemployment | Unemployment from aggregate-demand fluctuations; pro-cyclical. | Chunk 001 |
| Disguised Unemployment | Hidden unemployment where MP of labour ≈ 0. | Chunk 001 |
| Under-employment | Better-qualified workers in low-paid, low-quality jobs. | Chunk 001 |
| LFPR | Labour-force ÷ population aged 16–64. | Chunk 001 |
| Unemployment rate $u$ | Unemployed ÷ labour force. | Chunk 001 |
| Phillips Curve | Inverse relation between $u$ and inflation (originally wage growth). | Chunk 001 |
| Stagflation | Stagnation + high inflation occurring together. | Chunk 001 |
| Natural Rate of Unemployment $u^*$ | Frictional + structural; floor of unemployment. | Chunk 001 |
| Full Employment | Operating at $u^*$ — not zero unemployment. | Chunk 001 |
| Expectation-Augmented Phillips Curve | Phillips curve that shifts when expected inflation changes. | Chunk 001 |
| Adaptive Expectations | Updated from past observed values, gradually. | Chunk 001 |
| Rational Expectations | Use all info + true model; errors random with mean 0. | Chunk 001 |
| NAIRU | Unemployment rate at which inflation is stable. | Chunk 001 |
| Short-Run Phillips Curve (SRPC) | Downward-sloping at given $\pi^e$. | Chunk 001 |
| Long-Run Phillips Curve (LRPC) | Vertical line at $u^*$; no trade-off. | Chunk 001 |
| Money Neutrality | ↑M affects only nominal variables, not real. | Chunk 002 |
| Permanent Income Hypothesis | Consumption depends on expected/permanent income. | Chunk 002 |
| Aggregate Demand (AD) function | $Y = f(G, T, M/P)$. | Chunk 002 |
| Aggregate Supply (AS) function | $P = P^e(1+m)f(u, z)$. | Chunk 002 |
| Mark-up $m$ | Price-cost margin in price-setting; lower for more competitive economy. | Chunk 002 |
| Fooling Models | AS-AD short run: workers fooled, firms not (asymmetric info). | Chunk 002 |
| Lucas Critique | Past statistical relations break under policy-regime change. | Chunk 002 |
| Perfect Foresight | $P^e = P$ exactly; expectational error 0; money fully neutral. | Chunk 002 |
| Stochastic true-model | $Y_t = \alpha + \beta X_{t-1} + \gamma Y_{t-1} + \eta Z_{t-1} + \nu_t$. | Chunk 003 |
| Rational expectational error | $\nu_t = Y_t - E_{t-1}Y_t$; mean 0, variance $\sigma^2$. | Chunk 003 |
| Microfoundations | Macro relations built from optimizing micro decisions. | Chunk 003 |
| Lucas Supply Function | $y_t - y_p = f(p_t - E_{t-1}p_t)$; price surprise drives output. | Chunk 003 |
| Signal Extraction Problem | Distinguishing relative-price vs. aggregate-price changes. | Chunk 003 |
| Local vs. Global Information | Agents know own prices better than aggregate prices. | Chunk 003 |
| Price Surprise | $P_t > E_{t-1}P_t$ — drives short-run real effects. | Chunk 003 |
| Money Supply Rule | $M_t = \alpha y_{t-1} + \epsilon_t$; $\epsilon_t$ unanticipatable. | Chunk 003 |
| Policy Ineffectiveness Theorem | Only unanticipated money moves output (Sargent–Wallace 1976). | Chunk 003 |
| Endogenous expectations | Expected value derived within the same model that explains the actual variable. | Chunk 003 |
