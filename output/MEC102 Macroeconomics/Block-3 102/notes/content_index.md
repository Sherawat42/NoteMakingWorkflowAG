## Key Terms Glossary
| Term | Definition | First Appears |
|------|-----------|---------------|
| Average propensity to consume (APC) | Ratio $C_t/Y_t$ | Chunk 001 |
| Intertemporal budget constraint (IBC) | $C_1 + C_2/(1+r) = Y_1 + Y_2/(1+r)$ | Chunk 001 |
| Consumption smoothing | Equalizing consumption across periods despite income variation | Chunk 001 |
| Life Cycle Hypothesis (LCH) | Modigliani–Brumberg theory: smooth consumption over hump-shaped lifetime income | Chunk 001 |
| Permanent income | Long-run average income an individual expects | Chunk 001 |
| Transitory income | Random deviation from permanent income | Chunk 001 |
| Permanent Income Hypothesis (PIH) | Friedman: $C_t$ depends only on permanent income | Chunk 001 |
| Rational expectations | Expectations that don't differ systematically from outcomes | Chunk 001 |
| Random Walk Hypothesis (RWH) | Hall: $C_{t+1} = C_t + e_{t+1}$, changes are unpredictable | Chunks 001–002 |
| Consumption Capital Asset Pricing Model (C-CAPM) | Risk premium tied to $\text{Cov}(r, u'(C))$ | Chunk 002 |
| Subjective discount rate ($\rho$) | Rate of time preference in continuous time | Chunk 002 |
| Inada conditions | $f(0)=0$, $f'(0)=\infty$, $f'(\infty)=0$ | Chunk 002 |
| Ramsey-Cass-Koopmans (RCK) model | Infinite-horizon optimal growth model | Chunk 002 |
| Hamiltonian function | $H = F + \mu f$ — packages payoff + constraint | Chunk 002 |
| Co-state variable ($\mu$) | Continuous-time analog of Lagrange multiplier; shadow price of state | Chunk 002 |
| Steady state | Long-run equilibrium with constant variable values | Chunk 003 |
| Modified golden rule | $f'(k) = \rho + n$ — RCK steady-state condition | Chunk 003 |
| Golden rule | $f'(k_g) = n$ — maximizes steady-state per-capita consumption | Chunks 003–004 |
| Saddle path | Unique trajectory converging to a saddle-point steady state | Chunk 003 |
| No-Ponzi-Game (NPG) condition | Rules out infinite borrowing in decentralized RCK | Chunk 003 |
| Perfect foresight | Households exactly anticipate future $w$, $r$ | Chunk 003 |
| Ricardian Equivalence | Tax = debt financing under perfect foresight | Chunk 003 |
| Pontryagin's Maximum Principle | FOCs for continuous-time optimal control | Chunk 003 |
| Transversality condition | Terminal condition: $\mu_T x_T = 0$ (finite); $\lim \mu_t x_t = 0$ (infinite) | Chunk 003 |
| Overlapping Generations (OLG) framework | Finite-life agents (typically 2 periods); society lives forever | Chunks 003–004 |
| Basic dynamic equation (OLG) | $K_{t+1} = L_t s_t$, or $k_{t+1} = s/(1+n)$ | Chunk 004 |
| Dynamic efficiency | Cannot raise current consumption without lowering future | Chunk 004 |
| Dynamic inefficiency | Over-saving — Pareto improvement available by reducing capital | Chunk 004 |
| Fully funded social security | Contributions invested for and returned to same individual | Chunk 004 |
| Pay-as-you-go (PAYG) social security | Workers' contributions immediately fund retirees; effective return = $n$ | Chunk 004 |
