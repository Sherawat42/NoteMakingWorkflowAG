7.4.3 Likelihood Ratio Test  
Likelihood ratio test or the LR-test enables us to test whether adding a set of new 
variables to the existing model increases the explaining capacity of the model. 
We saw that Wald test requires the estimation of only the unrestricted model, 
whereas, the LM-test requires the estimation of the restricted model. Unlike these 
two tests, the likelihood ratio test or LR-test requires estimation of both restricted 
as well as the unrestricted models.  
Let us suppose that 𝜃 is a vector of parameter to be estimated having some 
restriction specified as the null hypothesis  𝐻଴ . The unrestricted and restricted 
maximum likelihood parameters of 𝜃 are denoted by 𝜃෠௨  and 𝜃෠ோ  respectively.

As said above, the LR-test enables us to test whether adding a set of new 
variables to the existing model increases the explaining capacity of the model. 
Using LR-test to test the simple null hypothesis against alternative hypothesis is 
not possible. This is because the degrees of freedom equals the number of 
parameters reduced as a consequence of imposing restrictions and in the case of 
testing the simple null hypothesis against alternative hypothesis, this would be 
equal to zero. Further, LR-test cannot be applied to test one distributional 
assumption against another as the likelihood functions of the two with different 
distributions will be unrelated.

7.5  LET US SUM UP 
Evaluation of a regression model could be made throuth the coefficient of 
determination, which indicates the percentage variation in dependent variables 
that be explained by the independent variables. Hypothesis testing in multiple 
regression models is carried out to examine if a finding is sufficiently close to the 
stated hypothesis associated with the unknown population parameter vector β. 
After providing an outline of the coefficient of determination R2, details of the 
two types of tests. Commonly used tests, viz., the t-test and the F–Test are 
discussed in this unit. In practise, we come across hypotheses which require 
linear restrictions on more than one coefficient. Testing the hypotheses in such 
cases can be done either by reparameterization or by using alternative tests like 
the Wald, Lagrange Multiplier or the Likelihood ratio tests. These tests have been 
detailed out in the last section of the unit.
