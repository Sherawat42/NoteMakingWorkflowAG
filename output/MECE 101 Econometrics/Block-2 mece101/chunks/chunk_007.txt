7.0 OBJECTIVES 
After going through this Unit, you will be able to 
 explain the concept of ‘Coefficient of Determination’ with an example; 
 outline the procedure for testing the statistical significance of a single 
parameter in an estimated regression model; 
 describe how the statistical significance of a group of parameters can be 
assessed by using the F-test; and 
 Discuss the tests for linear restrictions, viz., Wald, Lagrange Multiplier, and 
Likelihood Ratio tests. 
7.1 INTRODUCTION 
In the previous Unit, we discussed the specification of multiple regression 
models. We also derived the estimators of the parameters by applying the OLS 
and maximum likelihood methods of estimation. In this unit, we will first 
consider the importance of the concept of Coefficient of Determination given by 
R2. We then proceed to learn how to test for the significance of the estimated 
parameters for individual regressors. We will also learn how to interpret the 
results. The extent to which the independent variables together explain the 
variation in the dependent variable will also be seen. We finally learn about three 
procedures for testing the linear restrictions.

7.2.1 Over-Fitting 
Suppose we have a regression model with two explanatory variables, and we 
obtain 𝑅ଶ  value as 0.63. It implies that the two explanatory variables explain 63 
per cent variation in the dependent variable. Now, suppose, we add one more 
explanatory variable to the regression model, i.e., the number of explanatory 
variables is three. What will happen to the 𝑅ଶ  value? We can compare the 𝑅ଶ  
values of both the regression models since the dependent variable is the same. 
It is observed that when we add explanatory variables to a regression equation, 
the 𝑅ଶ  value increases (i.e., the explanatory power of the model increases). The 
𝑅ଶ  value never decreases when we add an explanatory variable. Thus, there is a 
tendency on the part of researchers to include more explanatory variables in a 
regression model. In such cases, even if logically not correct and statistically not 
significant, many explanatory variables get added to the regression model. We 
cannot trust the inferences drawn from such models! Therefore, a question arises 
is: where do we stop?
