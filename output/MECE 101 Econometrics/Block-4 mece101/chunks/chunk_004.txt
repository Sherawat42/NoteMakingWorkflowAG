15.5  JOINT SIGNIFICANCE IN QUALITATIVE 
RESPONSE REGRESSION MODELS 
As far as joint significance is concerned, as equivalent of the F test (in the linear 
regression model) there are various ways of testing multiple restrictions in Probit 
and Logit models. 
The most commonly used test, and most easily calculated test is the Likelihood 
Ratio (LR) Test . It is used when we wish to test our exclusion restrictions, i.e. 
whether we should or should not exclude a set of variables. The idea is a simple 
one: we are maximizing is the log likelihood function, and since variables are 
excluded from the regression relationship, the objective function declines. The 
question then is whether we have a significant fall in the log likelihood function 
value. Like the F-test in linear regression models, in LR test the joint hypothesis 
to be tested is that all the explanatory variables are simultaneously irrelevant 
versus at least one of the explanatory variables is relevant. The likelihood ratio 
statistic is given as follows:

15.7 LET US SUM UP 
Here is a summary of linear probability model (LPM), logit model, and probit 
model:  
Linear probability model (LPM): The LPM is a simple linear regression model 
that can be used to predict a binary outcome. The dependent variable is a 
dichotomous variable, such as "yes" or "no, " "success" or "failure, " or 
"purchased" or "not purchased." The independent variables can be continuous or 
categorical. The LPM assumes that the error term follows a normal distribution. 
 The LPM is a simple linear regression model where the dependent 
variable is a binary variable. 
 The coefficients in the LPM can be interpreted as the change in the mean 
of the dependent variable for a one-unit change in the independent 
variable. 
 However, the LPM does not consider the fact that the dependent variable 
is binary, and this can lead to biased estimates of the coefficients. 
Logit model : The logit model is a more sophisticated model than the LPM. It 
assumes that the dependent variable follows a logistic distribution. The logistic 
distribution is a skewed distribution that is centered at 0.5. The logit model can 
provide more accurate predictions than the LPM, especially when the dependent 
variable is close to 0 or 1. 
 The logit model is a nonlinear regression model where the dependent 
variable is a binary variable. 
 The coefficients in the logit model can be interpreted as the change in the 
log-odds of the dependent variable for a one-unit change in the 
independent variable. 
 The logit model is more appropriate for modeling binary variables than 
the LPM because it considers the fact that the dependent variable can only 
take on two values. 
Probit model : The probit model is another type of model that can be used to 
predict a binary outcome. The probit model assumes that the dependent variable 
follows a normal distribution. The probit model is like the logit model in terms of 
its predictive accuracy. However, the probit model is sometimes preferred 
because it is easier to interpret than the logit model.
