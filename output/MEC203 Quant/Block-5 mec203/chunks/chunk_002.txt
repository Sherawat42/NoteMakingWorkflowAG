16.4 LET US SUM UP

In this unit, we have discussed the extrema of a function and the condition under
which it attains (relative/ absolute) extrema. We started with single variable case
for simplicity extended the argument for multivariable cases. The emphasis was
on the technique of how to obtain extrema of a function, which is differentiable.

16.5 KEY WORDS

Local (relative) : A function attains local maximum at any
Maxima and Global particular point in the domain of definition
(absolute) Maxima implies that the value of the function is maximum

in the neighborhood of that point only, and the
function can assume higher values elsewhere.
This can be non-unique. The global maximum is
the highest value of the function with reference to
its entire domain and hence unique

Local (relative) : A function attains local minimum at any
Minima and Global particular point in the domain of definition
(absolute) Minima implies that the value of the function is minimum

in the neighborhood of that point only, and the
function can assume lower values elsewhere. This
can be non-unique. The global minimum is the
lowest value of the function with reference to its
entire domain and hence unique.
