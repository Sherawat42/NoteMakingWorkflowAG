## Section: §10.8 Taylor Series 🔴
- Polynomial approximation around x = a:
  `f(x) = f(a) + f'(a)(x−a) + f''(a)/2!(x−a)² + … + fⁿ(a)/n!(x−a)ⁿ + Rₙ`.
- Lagrange remainder Rₙ = f^{(n+1)}(x*)(x−a)^{n+1}/(n+1)! at intermediate point x* ∈ (a, x).
- Maclaurin series = Taylor at a = 0.

## Section: §10.9 Mean Value Theorem & L'Hôpital's Rule 🔴
- MVT: if f continuous on [a,b], differentiable on (a,b), then ∃ c ∈ (a,b) with `f(b) − f(a) = (b − a) f'(c)`.
- Alternative form: f(a+h) = f(a) + h f'(a + θh), 0 < θ < 1.
- L'Hôpital: for 0/0 or ∞/∞, `lim f/g = lim f'/g'` if latter exists.
- Examples: `lim (eˣ−1)/x = 1`; `lim ((1+x)ⁿ−1)/x = n`.
