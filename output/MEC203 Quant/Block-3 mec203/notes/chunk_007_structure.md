## Section: §12.8 Definite Integrals 🔴
- Concept: definite integral yields a number; defined on an interval.
- §12.8.1 Finding Area: rectangles approximation (left, right, midpoint heights).
- Worked: f(x) = x² + 1 on [0,2] with 4 rectangles (right = 5.75, left = 3.75, mid).
- §12.8.2 Definition via Riemann sum: ∫ₐᵇ f(x) dx = lim_{n→∞} Σᵢ f(xᵢ*) Δx.
- Worked Example 12.22: ∫₀³ (x² + 1) dx = 12 (using formula).

## Section: §12.8.3 Properties of Definite Integral 🔴
- ∫ₐᵇ 1 dx = b − a.
- ∫ c f = c ∫ f; sum/difference distributes.
- Splitting interval: ∫ₐᵇ = ∫ₐᶜ + ∫ᶜᵇ.
- Comparison: 0 ≤ f ≤ g ⇒ ∫ f ≤ ∫ g.
- Same bounds: ∫ₐᵃ = 0.
- Reversing bounds flips sign.
