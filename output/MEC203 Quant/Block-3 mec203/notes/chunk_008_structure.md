## Section: §12.9 Fundamental Theorem of Calculus 🔴
- Part 1: F(x) = ∫ₐˣ f(t) dt ⇒ F'(x) = f(x).
- Part 2: ∫ₐᵇ f(x) dx = F(b) − F(a) for any anti-derivative F.
- Two anti-derivatives differ by a constant.
- §12.9.1 Worked Examples 12.25–12.28.

## Section: §12.11 Improper Integrals 🔴
- Definition: limit of integration is ±∞ (or integrand unbounded).
- Evaluation rules: ∫_b^∞ = lim_{a→∞} ∫_b^a; symmetric for −∞.
- §12.11.1 Convergent vs Divergent: convergent if limit exists & is finite.
- Comparison theorem (f ≥ g ≥ 0 on [a,∞)): convergence/divergence transfers.
- Worked Examples 12.34–12.37.

## Section: §12.12 Integration with Partial Fractions 🔴
- Decompose rational p(x)/q(x) when deg p < deg q.
- Steps: factor denominator, write as sum of simpler fractions with unknown constants, solve constants by substituting strategic x values.
- Distinct linear factors: A/(x−a) + B/(x−b).
- Repeated linear factors: A/(x+c) + B/(x+c)² + …
- Non-linear (quadratic irreducible) factor: (Bx+C)/(x²+1).
- If deg p ≥ deg q: long-divide first, decompose remainder.
- Worked Examples 12.38–12.43 (begins; some continue into chunk 009).
