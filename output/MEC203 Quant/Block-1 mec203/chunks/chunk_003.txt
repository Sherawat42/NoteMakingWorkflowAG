1.2.7.1 Difference between the Concepts of ‘Relation’ and ‘Operation’

Let us now understand the difference between the two concepts ‘relation’ and
‘operation’, which 1s illustrated through the following examples for numbers: for
numbers 8 and 15, the notation 8 < 15 denotes a relation ‘is less than’; similarly,
the notation 8 # 15 denotes the relation ‘is not equal to’, and 3+5 = 8 denotes the
relation ‘is equal to’. Each of the relations does NOT give a new number, but,
tells some already existing fact, e. g. the notation 8 # 15 denotes the already
existing fact of 8 ‘not being equal to’ 15.

A relation returns a value TRUE or FALSE. For example:
3< 5 returns TRUE; 7< 5 returns FALSE.
8 # 15 returns TRUE; 8 # 8 returns FALSE.

On the other hand, an operation gives something new; in the following cases new
numbers: 8+15 gives new number 23; 8 — 15 gives new number — 7; and (+1 16)
gives a new number 4.

To apply the operation of ‘+’, we must have at least two numbers, therefore, ‘+’
is called a binary operation. On the other hand, to take a square-root (V), we
need only one number, therefore, operations like square-root () is called unary
operation.

For discussion in general, we need the concept of cross-product of sets.

Cross-Product of sets: for two non-empty sets A; and Ao, their cross-product
(Cartesian product), denoted as A; x Az, is the set of all ordered pairs (a1, az),
where a;€Aland a2€Az. The concept may be generalized to any finite number
of sets say Aj, Az, ... An. denoted as A7 X Azx ... X An. The cross-product of n
sets is the set of all n-tuples of the form (a1, a2. ..., an), where ai € Ai for I =1, 2,

Relation on a set X is a subset of cross-product of the X with itself n times,
where n is the arity of the Relation. For example, is-male involves a single
person, hence, it is a relation of arity one; is-mother-of involves two persons,
hence its arity is two. A relation returns as value exactly one of ‘true’ or ‘false’.
For example, if Sheela is not mother of Mohan, then the value of the relational
expression is-mother-of (Sheela, Mohan) returns false.

Operation on a set X is quite similar to the concept of relation. An operation on
X maps the cross-product of X with itself n times, where n is the arity of the
operation. But it returns, as value, an element of X itself. For example, operation
of square on N, the set of natural numbers, involves a single number, hence, it is
an operation of arity one; the operation of sum involves two numbers, hence its
arity is two. But in both the cases of square and of sum, the value returned is a
single number/ member of X.
