By using the similar arguments that we used to prove the theorems in unit-22 we

formulate Lagrangian for continuous dynamic optimisation problems, each with

equality constraint and with fixed final state. From the Lagrangian we derive the

Hamiltonian functional and the state, the necessary condition for optimisation.

The conditions that need to be solved in order to
find optimal control. Boundary conditions arise
because either final state or final time or both are
free (unspecified) in objective functional.

In optimal control theory a control is a variable
chosen by the controller or agent to manipulate
state variables similar to an actual control value.
Unlike the state variable, it does not have a
predetermined equation of motion. The goal of
optimal control theory is to find some sequence of
controls (within an admissible set) to achieve an
optimal path for the state variables.
